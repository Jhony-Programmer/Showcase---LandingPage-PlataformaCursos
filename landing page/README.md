## 🎯 Objetivo & Evolução de Habilidades

O propósito deste projeto no meu portfólio é demonstrar a base de desenvolvimento front-end sem a dependência de bibliotecas ou frameworks externos. Ele reflete o domínio dos conceitos essenciais de estilização e arquitetura de página.

### O que este projeto evidencia na minha trajetória:
- **Estruturação Semântica:** Uso das tags semânticas do HTML5 (`<header>`, `<main>`, `<aside>`, `<form>`) para uma estrutura limpa e acessível.
- **Layout com CSS Flexbox:** Distribuição dos elementos do cabeçalho (`header`) e da seção principal (`main`) através de alinhamentos com `display: flex`, `justify-content: space-between` e `align-items`.
- **Identidade Visual & Tema Escuro (Dark Theme):** Aplicação de contraste moderno com fundo escuro (`rgb(34, 34, 34)`), texto claro e destaques com cores de acento (`burlywood` no logo e tons de roxo nas chamadas de ação).
- **Estilização de Formulários e Controles:** Construção de inputs de texto com cantos arredondados (`border-radius: 30px`), bordas limpas e botão de ação estilizado.
- **Micro-interações:** Efeitos visuais nos links da barra de navegação com transição suave (`transition: 300ms`) ao passar o mouse (`:hover`).

## 🧩 Seções da Landing Page

1. **Header / Navegação:**
   - Logotipo da plataforma com destaque visual (**Javie** *Course*).
   - Menu de links de navegação (`Home`, `App`, `Pricing`, `Contact`).
   - Botão de login (`Sign in`) em formato de pílula contornado.

2. **Hero Section (Principal):**
   - Título de alto impacto focado na formação: **Seja Desenvolvedor Web FullStack**.
   - Texto persuasivo destacando as tecnologias abordadas na formação (HTML, CSS, JavaScript, React, Node.js, Express e bancos de dados).
   - Ilustração de tecnologia em destaque.

3. **Captura de Leads (Formulário):**
   - Campos simplificados de Nome e E-mail com botão **Enviar >** para conversão de novos alunos interessados.

## 💻 Como Executar o Projeto Localmente

> **Nota:** Este projeto não possui deploy online e está disponível exclusivamente através deste repositório no GitHub.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/showcase-stacks-java.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd "landing page"
   ```

3. **Abra o projeto:**
   - Basta dar um duplo clique no arquivo `index.html` para abrir diretamente no seu navegador padrão;
   - Ou utilize a extensão **Live Server** no Visual Studio Code para recarregamento automático.
